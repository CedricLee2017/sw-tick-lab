# SW Tick Lab — 魔靈召喚 天空之役 符文配裝實驗室

以 **Speed Tick（出手順位）** 為核心的符文配裝工具。上傳 SWEX / SWOP 匯出的 JSON，就能分析帳號、比較魔靈，並用分支定界演算法在幾百毫秒內找出「剛好達到指定 Tick」的最佳配裝。

**線上使用：<https://sw-tick-lab.pages.dev>**　|　**原始碼：<https://github.com/CedricLee2017/sw-tick-lab>**

> 所有運算都在你的瀏覽器完成，帳號資料不會上傳到任何伺服器。

## 功能

- **匯入存檔**：支援 SWEX / SWOP JSON，自動偵測魔靈、符文、建築等級與已裝備狀態。可先載入內建的示範帳號試玩。
  - 相容 **SWEX v1.1.0**：裝備中的符文只會出現在 `unit_list[].runes`，工具會自動合併並以 `rune_id` 去重。
  - 同時解析 **神器（Artifact）**：頂層 `artifacts` 與 `unit_list[].artifacts` 會以神器 ID 合併，已裝備神器以魔靈身上的 owner 為準。
  - 使用 sw-exporter 官方 stat / set ID（速度 = 8、暴走 = 13、意志 = 15…），並正確換算遠古符文（`class` / `rank` +10）。
  - 容忍多層包裝（`data` / `save` / `swop`）、以 id 為 key 的物件格式，以及字串形式的套裝 / 屬性名稱。
- **帳號總覽**：魔靈數量、符文數量、Speed Tick 分布、一速排名、套裝統計。
- **速度實驗室**：Tick ↔ 速度雙向換算、各 Tick 門檻表、建築與隊長技加成試算、隊伍出手順序模擬。
- **RTA 世界競技場**：使用存檔的 `favorite_unit_list`（我的最愛）列出常用魔靈，依 RTA 獨立配裝的速度由高到低排序。
  - RTA 符文 / 神器來自 `world_arena_rune_equip_list` / `world_arena_artifact_equip_list`，與一般配裝完全獨立；同一顆符文可同時出現在兩邊。
  - 可切換「無速度隊長」/「有速度隊長」，速度隊長 % 可自行輸入；RTA Tick 以 1.5% / Tick 計算。
  - 每隻魔靈可展開查看 RTA 六顆符文、兩件神器、HP / ATK / DEF / EHP 與速度。
- **一鍵配符**：指定魔靈與 Tick（或面板速度），自動計算符文速度需求，列出所有符合條件的配裝（每頁 30 組）。
  - **快速預設配符**：一鍵套用常用配置（套裝、主屬性、數值條件、Focus 比重、排序），套用後按「開始配符」即可。內建：
    - **極限輸出風丑**：自動選風丑（Lushen）、憤怒 ×4 + 刀刃 ×2、#2 攻擊% / #4 暴傷 / #6 攻擊%、暴率下限 100%，Focus 攻擊 / 暴率 / 暴傷 各 10 分，並以傷害排序。
    - **迅速1速**：套用在目前選取的魔靈，迅速 ×4 + 意志 ×2、#2 速度、不設速度下限，Focus 速度 10 分，依速度排序。候選 11 顆（每位置最快符文都在其中），實測可達符文庫的理論最高速。
    - **暴走意志百抗T5**：套用在目前選取的魔靈，暴走 ×4 + 意志 ×2、#2 速度 / #4 體力%、抵抗下限 100%、Tick 5，Focus 體力 / 防禦 / 抵抗 / 速度 各 10 分，依 EHP 排序（#6 留給抵抗或體力%，由 EHP 排序挑最好的一組）。
    - **EHP最大化**：套用在目前選取的魔靈，能量 ×3（3×2 件套）、#2 體力% / #4 防禦% / #6 體力%，Focus 體力 / 防禦 各 10 分，依 EHP 排序。
  - 以分支定界 + Web Worker 執行，每位置候選上限 15 顆（15⁶ = 1,139 萬組）。結果會顯示「組合空間」，並可在進階選項切換搜尋預算：快速 200 萬 / 標準 800 萬 / 完整 1,200 萬 / 極限 4,000 萬節點（約 1.5 / 5 / 8 / 30 秒）。
  - 運算時不預設任何「排序目標」：先完整找出符合條件的組合，結果產生後再依「排序」欄位（綜合評分 / 速度 / 體力 / 防禦 / 攻擊 / EHP / 暴率 / 暴傷 / 抵抗 / 命中 / 符文效率 / 焦點契合 / 傷害）重新排列，換排序不會重算。
  - 每頁顯示 30 組，可翻頁瀏覽；結果會全部保留（最多 200 萬組，超過時停止以避免記憶體不足）。
  - 支援 4 件套 + 2 件套、3×2 件套、套裝件數驗證、套裝速度加成（迅速）；可開啟「允許破套」只強制主套 4 件，或勾選「無形」讓 1 顆無形符文補足缺少的套裝。嚴格套裝找不到或速度不足時，會自動改用破套再算一次。
  - 可指定 #2 / #4 / #6 主屬性（速度、固定體力 / 固定攻擊 / 固定防禦、體力% / 攻擊% / 防禦%、暴率、暴傷、命中、抵抗）。固定值主屬性也會完整計入 HP / ATK / DEF / EHP。
  - **配神器（獨立頁面）**：選擇一隻目前帳號的魔靈，直接使用牠**目前裝備的符文（固定）**與面板，不需要先跑配符、也不會重新組合符文。魔靈可用名稱即時搜尋；頁面也會列出已儲存的符文組合（配裝收藏），點一下就會選取該魔靈與符文並立即計算神器。依單一技能傷害從屬性神器與類型神器各挑前 5 件（共 10 件、25 對），每對再套用到這組符文上比較。
    - 神器屬性 / 類型會依魔靈自動固定（例如風丑＝風屬性、攻擊型，兩者都包含無形）；可設定兩個神器位置的主屬性、敵方屬性，以及每個位置最多 5 條神器副效果焦點（最小／最大 + 權重 1–10）。頁面有獨立傷害面板可選技能與敵人設定。
  - **Speed Tick 計算器**：獨立頁面（不需匯入存檔），介面分成 **Monsters / Advanced / Turn Order / Tick View / Saves / FAQ** 六個頁籤，參考 SWGT 的 Speed Tick Bracket Calculator。藍隊＝攻擊方、紅隊＝防守方；預設不加入任何魔靈，可搜尋名稱或用「從儲存庫載入」一鍵加入配裝儲存庫的魔靈，或整隊加入預設隊儲存庫（防守隊自動放紅隊）：
    - 上方可分別設定藍隊／紅隊的天空圖騰與速度隊長技、每 Tick 攻擊條 7%（一般）／1.5%（RTA）／4.5%（討伐），以及排序方式；下方是各 Tick 的速度門檻色帶。
    - **Monsters**：搜尋名稱／屬性加入魔靈（每隊最多 15 隻、兩隊共 30 隻），每隻一張卡片：大頭像、隊伍、順位、迅速套裝、基礎速度、Speed Lead（Default 或自訂）、符文速度、神器速度 Buff +%，並顯示 Total Speed 與降速／一般／Buff 三段速度及各自的 Tick。
    - **Advanced**：MONSTERS 摘要表（可直接加減符文速度）、TICKS 逐 Tick 攻擊條矩陣（0–70 欄，出手以隊伍顏色標示）、ATTACK BAR BOOST／SPEED MODIFIER／ADDITIONAL SPEED 三個可逐格輸入的矩陣（三者都只在該 Tick 生效；速度增減與額外速度可用「範圍套用」一次填 From～To）。
    - **Turn Order**：每次出手的 Tick 徽章、魔靈、作用中的速度增減、出手時攻擊條與「領先下一名的差距」。
    - **Tick View**：每個 Tick 的攻擊條排序與是否出手。
    - **Saves**：把目前設定（含拉條 / 速度增減 / 額外速度）命名儲存、備註、讀取與刪除；工作狀態也會自動存在瀏覽器。
  - **神器追傷計算器**：獨立頁面，依 HP / ATK / DEF / SPD、追傷 % 與技能段數計算 `floor(HP×h%) + floor(ATK×a%) + floor(DEF×d%) + floor(SPD×s%)`；可選魔靈帶入目前面板，或直接點選「儲存庫」的魔靈符文組合帶入該組數值；也能從神器排行把追傷效果「套用／加入」，並和技能傷害比較。
  - **預設隊**：解析存檔的 `deck_list`，列出所有類型／序號的預設隊；顯示隊長、隊員、每隻魔靈在該預設隊的符文與神器快照，可依類型篩選與搜尋魔靈。隊伍詳情會依該隊的符文配置計算每隻魔靈的速度、Speed Tick 與**速度順序**（同一速度並列同名次），隊長的**速度隊長技**會自動套用（只有符合屬性與內容範圍的隊長技才計算，例如競技場專用隊長技不會套用到據點戰）；清單上的小頭像也會直接標示 `T4` 等 Tick 徽章。類型名稱包含競技場、公會戰（進攻）、異界（三頭）、迷宮（一般／限速／限時／炸彈／首領）、試練之塔、屬性之塔、天空之塔、次元團戰（1P／2P／3P）、據點戰（進攻）、混沌、卡伊洛斯、異界（單頭）、次元與討伐戰；尚未命名的類型會以「類型 9、類型 18」等編號列出（1–27）。
  - **防守隊**：同時解析 `defense_deck_info`（競技場防守，含戰力）、`server_arena_defense_deck_info`（伺服器競技場防守）與 `guildsiege_defense_deck_unit_list` ＋ `guildsiege_defense_deck_equip_list`（據點戰防守，多隊），在預設隊頁以「競技場防守（本機）／競技場防守（伺服器）／據點戰防守」分組，並顯示同一套符文與神器快照。
  - **符文限制（排除／包括）**：可排除指定符文，或包括指定符文並固定使用；兩者都能直接加入「整隻魔靈目前裝備的符文」。包括每個位置最多一顆，排除與包括互斥。
  - **符文鎖定**：在符文倉庫、魔靈詳情、配符結果或 RTA 詳情中都可鎖定個別符文。已鎖定的符文不能再被其他魔靈配符使用，只能留在原本裝備的魔靈身上。
  - **儲存庫**：分成「預設隊儲存庫」與「配裝儲存庫」兩區。預設隊頁可「儲存整隊」（整隊快照，含每隻魔靈的符文與神器），也可在隊伍詳情中「儲存這隻」（單一魔靈，會進到配裝儲存庫）。配裝儲存庫沿用原本的帶入配符／一鍵上符／一鍵解鎖／一鍵解符；預設隊的每隻魔靈也能單獨「帶入配符」。
  - 收藏詳細視窗可 **一鍵上符**：把該組 6 顆符文標記為裝備在對應魔靈身上（只修改本工具的本機資料，不會修改遊戲存檔；原本穿著這些符文的魔靈會自動失去該符文）。另有「一鍵解鎖」與「一鍵解符（解除排除／包括）」。
  - 配符結果可一鍵對整組符文執行：上符、鎖符、解除鎖符、排除、解除排除、包括此組合與取消包括。
  - **Focus 焦點屬性**（最多 5 組，比重 1–10）：有設定焦點時，每個位置就是用這些比重挑出「最符合焦點的 15 顆」候選符文（未被焦點的屬性權重為 0），再從中搜尋組合。候選上限固定 15 顆（15⁶ = 1,139 萬組），可在 6–15 之間調整。
  - 每組結果可展開查看完整符文卡：套裝、位置、+15、主屬性、固有屬性、全部副屬性（含精煉）、符文 ID、原本裝備的魔靈、效率 %；「配符清單」可一次複製全部資訊。
  - 可設定 HP / 攻擊 / 防禦 / 速度 / 暴率 / 暴傷 / 命中 / 抵抗下限（以含一般召喚師技能的實戰數值篩選）。
  - **技能傷害計算**：使用 SWARFARM 技能倍率，把每組配裝的實戰數值（含一般召喚師技能；公會技能依勾選）代入所選技能，支援段數、暴擊 / 平均、滿技、ATK Buff、破防、烙印、無視防禦、目標體力與速度縮放；結果可依傷害高低排序。第一階段不含神器；神器技能暴傷、屬性傷害與追傷在第二階段計算。
  - 預設配符模式為「面板速度 0」（不設速度下限）；也可切換成 Tick 目標。攻擊強化（ATK Buff +50%）預設關閉，需要時再勾選。
  - 配符前先顯示「目前符文上限」；若目標 Tick 不可能達成會直接提示，不會空等。
  - 魔靈選單只列出帳號內實際擁有的魔靈，避免選到圖鑑中但沒有資料的魔靈而算出錯誤上限。
  - Worker 載入失敗、逾時或網站更新造成舊頁面失效時，會顯示可重新整理的錯誤訊息。
- **一鍵配隊（配置預設隊）**：先選 3～5 隻魔靈，再按一次就配好整隊符文；同一顆符文不會分給兩隻魔靈。
  - 先決定隊型再配符：內建「速隊長＋提條＋主力打手」「T5 百抗坦克 ×3」「競技場 4 人」「RTA 5 人」與自訂隊型，也支援 3／4／5 人互換。每隻可調整角色、權重、速度條件（面板速度／目標 Tick 二選一，預設面板速度）、攻擊順序、提條 %、速度強化、神器「速度增加效果 +%」、抵抗／暴率下限、4 件套＋2 件套與 #2／#4／#6 主屬性。**速度隊長技 %** 改成數值輸入（預設 0）：填入 30 就是全隊基礎速度 +30%，每一隻的卡片還可個別覆寫（留空 = 跟隨全隊、0 = 這隻不吃），對應只有部分屬性／內容吃得到的隊長技。面板速度輸入的是「基礎速度與隊長技以外的額外速度」，面板總速 = 基礎 + 隊長技 + 額外；選了面板速度就不會再套用目標 Tick。提條角可按「提條／強化帶入後續」把提供的數值一鍵套用到後面出手的成員（來源自己不會套用）。
  - 可從「預設隊儲存庫」直接載入整隊（可選擇同時固定當時的符文）。載入後或切換隊型時，會依魔靈技能自動安排角色與出手順序：有速度隊長技的當速隊長（隊長技 % 自動帶入）、剩下有「增加攻擊條」技能且基礎速度最高的當提條、其餘依隊型補打手／輔助；順序固定提條 → 打手 → 輔助 → 速隊長。預設配裝：提條迅速＋意志、速體體；速隊長與打手迅速＋刀刃、速傷攻、暴率下限 100%。仍可再手動調整角色、順序與配裝。
  - 三階段引擎：每隻魔靈先產生 Top-K 候選（有界分支定界，只保留需要的組數）→ Beam Search 在「整隊符文不重複」的前提下聯合挑選 → 1-opt 局部改良；候選不足時會自動重新搜尋避開已用符文的配裝，同型隊伍（例如三隻百抗坦克）也能完成。
  - 隊伍分數 = Σ（每隻權重 × 該角色目標分數 ÷ 個人最佳），一速看速度、打手看期望傷害代理值、坦克看 EHP、輔助看綜合值；不是「先配先贏」的貪心法。
  - V1 只計入**速度隊長技**，其他隊長技不套用；RTA 模式沿用 1.5% Tick。
  - **即時接速試算（鏡像防守）**：第一隻視為起手、沒有接速下限；之後每一隻都要贏過「和你起手同速的鏡像防守」在那個 Tick 的攻擊條（攻擊條可以溢出 100%，同攻擊條時進攻方先動），而不是只看自己人有沒有滿 100%。提條 % 與速度強化都從起手出手後的下一個 Tick 才生效。看到的是「最低不被插隊速度」**以及它怎麼組成**（例如最低 257＝基礎 103 ＋ 額外 154；有隊長技時會多一段「隊長 31」）、對手攻擊條、我方攻擊條，以及 T4 你風格 → T5 你風武士 → T6 你風忍 → T7 對手風格的鏡像預測；也可以手動改鏡像對手速度（預設 0 = 同起手）。可單隻按「套用下限」或一次按「全部套用接速」。接速只影響顯示與按鈕，不會自動改寫原本的配符條件。速度強化為 +30%，神器「速度增加效果 +%」會再放大這個 Buff（例如 +20% → Buff 36%）。
  - 開跑前顯示每個位置的符文供給；結果可切換最多 4 組替代隊伍、查看速度順序、固定某一隻的符文後重配其他魔靈、整隊上符（一次寫入、不重複）、鎖定整隊、儲存到儲存庫（類型顯示「自訂配隊」）與複製清單。
  - **結果顯示**：每隻魔靈一張卡片，面板數值（體力／攻擊力／防禦力／速度／暴率／暴傷／抵抗／命中／EHP）**一行一項**，基礎值與綠色加成並列；符文依遊戲位置 `1 → 2 → 3 → 4 → 5 → 6` 排成六角符文盤；目前裝備的神器收在卡片下方（一鍵配隊只配置符文，神器不計入面板數值）。
  - **設定會保留**：配隊條件、成員與上一次的結果會自動存在瀏覽器，切去其他頁面再回來（或重新整理）都不會不見；換帳號時舊結果會自動清除。
- **符文管理**：依位置、套裝、星數、稀有度、副屬性搜尋與排序，快速找出可替換的符文。
- **神器倉庫**：依類型（屬性 / 類型）、屬性、效果文字、裝備狀態搜尋與排序；每件顯示 +15、主效果、副效果（含強化次數）、品質、神器 ID 與裝備魔靈，魔靈詳情也會列出已裝備神器。
- **魔靈圖鑑**：1987 隻魔靈基礎數值、覺醒狀態、現有配裝、神器與速度。
- **魔靈召喚記錄**：依 `create_time` 列出所有原4 / 原5 魔靈的取得時間（含背包 / 保管箱），可依原生星數、屬性、名稱搜尋與分頁。SWEX / SWOP 匯出檔沒有逐筆召喚 API，關卡掉落、活動贈送與合成也會一併列入。
- **設定**：建築等級覆寫、隊長技 / Buff 預設、RTA 模式、磨石與候選數、配裝紀錄、匯出 / 清除本機存檔。

## Tick 公式

```
Tick = ceil(10000 / (速度 × 7))
所需速度 = ceil(10000 / (Tick × 7))
```

- RTA 模式下每 Tick 為 1.5%，係數改為 `10000 / (速度 × 10)`；RTA 頁固定使用這個 Tick 基準。
- RTA 頁只計入 RTA 符文 / 套裝 / 神器與速度隊長，不套用一般建築、競技場圖騰或 Buff。
- 例：滿等速度圖騰 +15%、隊長技 +28%、迅速套裝 +25%，要達到 **Tick 5（286 速）**，工具會自動回推需要的符文速度。
- 戰鬥速度計算：`base + ceil(base × 百分比加成 / 100) + 固定值`；百分比含速度圖騰 / 隊長技 / 速度 Buff，迅速套裝為 `ceil(base × 25 / 100)`。
- **Speed Tick 計算器**（與 SWGT 相同）：`ceil((1 + 圖騰% + 隊長% + 迅速 25%) × 基礎速度 + (符文速度 − 迅速加成))`；每個 Tick 只有攻擊條最高且 ≥ 100 的一隻出手，出手後歸 0。拉條／速度增減／額外速度都只在指定 Tick 生效，正向速度增減會被神器「速度增加效果」放大，額外速度 % 則加進圖騰／隊長桶。
- **一鍵配隊接速（鏡像防守）**：提條與速度強化都在提條角出手後才生效。面板速度 = `基礎速度 + ceil(基礎速度 × 速度隊長技% / 100) + 額外速度`（隊長技可全隊設定，也能逐隻覆寫）。設起手 Tick 為 `T`、`有效 Tick 數(n) = n + Buff% × max(0, n − T)`，則
  `對手攻擊條(n) = 鏡像對手速度 × 每 Tick 攻擊條% × n`
  `我方攻擊條(n) = 面板速度 × 每 Tick 攻擊條% × 有效 Tick 數(n) + 提條%`
  接速最低速度 = 最小的整數，使 `我方攻擊條(目標 Tick) ≥ 對手攻擊條(目標 Tick)`（同攻擊條時進攻方先動）。例：風格 391（T4）、提條 30%、速度強化 30% → 風武士 T5 最低 289、風忍 T6 最低 291；風格 341（T5）→ 257 / 258。速度強化 Buff 基準為 30%，神器「速度增加效果 +%」會放大成 `30 × (1 + 神器%)`。
- EHP：`HP × (1140 + 3.5 × 防禦) / 1000`，使用含召喚師技能的實戰 HP / DEF 計算。
- **面板 vs 實戰**：畫面顯示的 HP / ATK / DEF / CD 是遊戲內魔靈面板（只有符文、套裝與神器主效果），不含召喚師技能與競技場 / 屬性塔加成；傷害與 EHP 則使用加上一般召喚師技能後的實戰數值。速度為了 Tick 正確，兩種版本都含速度圖騰 / 隊長技 / Buff。

## 技能傷害估算

- 技能倍率來自 **SWARFARM API**，資料存於 `public/data/skills.json`（可用 `npm run skills` 重新產生）。
- 召喚師技能（Battle）一律計入傷害與 EHP，但不會加進面板數值；競技場圖騰、屬性塔也視為一般技能加成。數值沿用滿等：競技場攻擊 / 體力 / 防禦 20%、暴擊傷害 25%、屬性攻擊塔 21%；速度圖騰 15% 另計入 Tick。
- 公會技能（Guild）預設**不計入**：配符頁的「計入公會召喚師技能（傷害 / EHP）」勾選可加入 20% / 25% 公會加成，EHP 與傷害排序會同步切換。
- 每段傷害：`實戰數值 × 技能倍率 × (烙印 × 暴擊係數 + 滿技傷害%) × 防禦減傷`。滿技與暴擊是**相加**（SWOP 的算法），不是相乘。
- 暴擊係數：必暴 `1 + 暴傷% / 100`；平均 `1 + 暴率% × 暴傷% / 10000`；普通 `1`。
- 防禦減傷：`1000 / (1140 + 3.5 × 敵人防禦)`；破防時敵人防禦 × 0.3；無視防禦時為 `1000 / 1140 ≈ 0.877`。
- 結果同時顯示 **每段傷害 × 段數 = 總傷害**；SWOP 的 DMG 欄位對應「每段傷害」。
- 已用同一份存檔、同一組符文與選項對照 SWOP：Lushen S3「Amputation Magic」（0.68 × ATK、3 段、無視防禦、ATK Buff、滿技 +30%、暴傷 186%）→ 兩邊每段皆為 **6,720**。
- 未計屬性克制、暴擊抵抗、部分特殊被動與需實戰條件的技能，數值僅供比較排序。

## 神器（Artifact）

- 神器效果 ID 對照採用 **sw-exporter `mapping.js`** 的 artifact 定義（200–226、300–309、400–411），介面顯示中文效果；主效果 100 / 101 / 102 分別為固定體力 / 攻擊 / 防禦。
- 已裝備神器只存在 `unit_list[].artifacts`，頂層 `artifacts` 是未裝備清單；解析時兩邊以 `rid` 合併，並以魔靈身上的 `occupied_id` 為裝備擁有者。
- **面板**：魔靈詳情與目前裝備顯示的神器主效果（固定體力 / 攻擊 / 防禦）會計入 HP / ATK / DEF / EHP；**配符完全不含神器**，神器在「配神器」頁才加上。
- **傷害**：「配神器」只計入技能傷害，包括技能 1–4 暴擊傷害、技能 3／4 暴傷、單體技能暴傷與對指定屬性傷害；追加傷害（追傷 218–221）已獨立到「神器追傷計算器」。
- **神器追傷計算器**：可手動輸入或帶入魔靈目前面板，計算 `每段追傷 = floor(HP×h%) + floor(ATK×a%) + floor(DEF×d%) + floor(SPD×s%)`，再乘技能段數；也可從神器排行套用／加入追傷效果，並和技能傷害比較。每個屬性分開無條件捨去，追傷不受暴擊、防禦減傷與屬性增傷影響。

### 配神器流程

1. 在「配神器」頁用名稱搜尋選擇魔靈，或直接點選已儲存的配裝收藏；系統讀取牠目前裝備的 6 顆符文（或收藏的符文組合）與面板，**不重新組合符文**。
2. 系統依魔靈自動固定神器屬性 / 類型：例如風丑（風 / 攻擊型）只會用「風屬性（含無形）」與「攻擊型（含無形）」神器，不會混入其他屬性 / 類型；再依兩個神器位置的主屬性篩選。
3. 神器副效果焦點（每個位置最多 5 條）：每條選一個效果並設定最小／最大，**所有選定效果都符合**才會進入候選。契合度 = `Σ(權重 × 數值 ÷ 該效果上限) ÷ Σ權重`（0–100%）。
4. 用目前這組符文，依技能傷害對神器評分。有焦點時先依契合度取前 5 件（同分再比傷害）；沒有焦點時只依傷害取前 5 件。兩個位置合計 10 件。
5. 5×5 = 25 對神器，每對都套用到同一組目前符文，重新計算技能傷害（加上神器主屬性與效果）。
6. 依技能傷害排序，顯示前 10 對；技能由頁面上的傷害面板選擇。

### 神器追傷計算器

- 可手動輸入 HP / ATK / DEF / SPD，或選一隻魔靈帶入目前面板。
- 輸入四種追傷 %（218 HP、219 ATK、220 DEF、221 SPD）與技能段數，立即顯示每段與總追傷。
- 神器追傷排行會用目前面板與段數，計算每件神器的追傷；可「套用」或「加入」效果。
- 可選擇性輸入技能倍率、敵方防禦、暴擊傷害與攻擊強化，比較追傷與技能傷害。

> 配神器只評估 25 對神器 × 1 組目前符文 = 25 次完整計算，通常在 100 ms 內完成，不會重新搜尋 15⁶ 符文組合。

## 配符沒有結果？

1. 先看配符頁的 **「目前符文上限」**：如果它低於目標速度，代表即使全選最高速符文也達不到。可降低 Tick、清除套裝限制、放寬 #2/#4/#6 主屬性，或勾選「允許破套」。
2. 若「開始配符」一直停在運算中，或出現「運算模組載入失敗」，請按 **Ctrl + F5**（Mac：Cmd + Shift + R）重新整理。網站更新後，舊分頁可能找不到新的 Worker 檔案。
3. 建築一律以全滿等計算；若匯出檔沒有建築等級也不影響。需要套用存檔中的實際等級時，可到 **設定 → 從存檔偵測**。一般召喚師技能一律計入傷害與 EHP；公會技能預設不計入，可在配符條件或傷害面板勾選「計入公會召喚師技能」。
4. 舊版網站快取的存檔會在新版自動清除，並提示重新匯入；這是因為舊解析的 stat / set ID 有誤，沿用會算出錯誤數值。
5. 匯入後如果有「未知套裝 / 未知魔靈」警告，可在匯入頁按 **「複製診斷」**，把複製到的數量與格式資訊回報，不需要提供完整符文內容。
